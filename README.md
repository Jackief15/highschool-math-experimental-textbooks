# 《高中數學實驗教材 第一至六冊（全套完整版）》LaTeX 數位轉錄專案

本專案依據教育部高中數學實驗教材編輯小組出版之《高中數學實驗教材》系列歷史教材原始掃描檔，進行高品質 \LaTeX{}（XeLaTeX）數位化轉錄與重排，涵蓋共同／自然組（第一至六冊）與社會組（第三至六冊）共十冊全套完整版：
- 第一冊（高一上，1973年修訂版）
- 第二冊（高一下，1973年初版）
- 第三冊：自然組（高二上，1975年再版）／社會組（高二上，1975年再版）
- 第四冊：自然組（高二下，1976年三版）／社會組（高二下，1976年三版）
- 第五冊：自然組（高三上，1975年再版）／社會組（高三上，1975年再版）
- 第六冊：自然組（高三下，1976年再版）／社會組（高三下，1975年初版）

## 教材來源與背景說明

- **教材典藏來源**：[中華民國數學會（TMS）數學教育推廣平台 — 高中數學實驗教材](https://sites.google.com/math.ntu.edu.tw/tmseducation/學級資源/10-12年級/高中數學實驗教材)
- **歷史背景**：本教材為教育部高中數學實驗教材編輯小組於民國六十二年至六十五年（1973–1976）出版之實驗教材，為臺灣中學數學教育發展史上極具代表性之「新數學（New Math）」運動核心文獻，強調公理化體系、集合論語言、向量空間、線性映射、抽象代數結構與嚴謹幾何邏輯推理。
- **數位化目標**：本專案以現代高品質之 \LaTeX{}（XeLaTeX）重排，校訂原書鉛字印損、錯別字與排印訛誤（詳見各主檔目錄前勘誤表），並以 TikZ 重繪全書數百幅高解析向量幾何圖、立體投影圖、極圖映射對照圖與函數圖形，提供數學教學、歷史研究與數位典藏之標準參照本。

## 編譯說明

本專案使用 `XeLaTeX` 進行編譯，以確保中文與數學字型正常渲染：

### 1. 編譯全冊主檔（自動輸出中間檔至 `build/`、成品至 `pdf/`）
在專案根目錄下執行：
```bash
# 使用 Makefile 一鍵編譯單冊或全套十冊
make B1          # 第一冊 -> pdf/main_B1.pdf
make B3s         # 第三冊（社會組）-> pdf/main_B3_社會組.pdf
make all         # 全套十冊一鍵編譯
make clean       # 清除 build/ 編譯中間檔

# 或直接使用 verify_book.py（含靜態排版檢查 + 兩次 XeLaTeX 編譯 + Log 驗證）
python3 tools/verify_book.py tex/main_B1.tex --compile 2
python3 tools/verify_book.py tex/main_B6_社會組.tex --compile 2
```

### 2. 單獨編譯特定章節
```bash
python3 tools/verify_book.py chapters/B6/Chapter1_main.tex --compile 2
# 中間檔與單章預覽 PDF 會自動輸出至 build/chapters/B6/，不污染原始碼目錄
```
